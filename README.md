# 보문사 (普門寺) — 3D 산사 명상 및 참배 도량

서울 성북구 보문동에 위치한 보문사의 도량을 3D 인터랙티브 가상 공간으로 구현한 웹 애플리케이션입니다.

## 주요 기능
- **경내 탐방**: 호지문, 묘보탑(9층탑), 대웅전, 산신각, 석굴암을 자유롭게 거닐며 3D로 둘러보기
- **법당 참배 및 공양**: 각 법당에 입장하여 촛불 켜기, 향 피우기, 목탁 및 싱잉볼 타종
- **경건한 삼배(절하기)**: 불교식 절하기 동작과 회향 발원
- **호흡 명상**: 들이마시고 내쉬는 리듬에 맞춘 고요한 마음챙김 명상
- **마음 발원문**: 소원을 작성하고 법당에 올리기
- **모바일 완벽 지원**: 스마트폰 터치 조작 및 PWA(홈 화면에 추가) 지원
